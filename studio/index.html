          Connecting this computer to the box
          
        
            
      1. On the Kindle: Choose → Settings → Pair watch. That opens the box's pairing window for 2 minutes. It is named for the watch but pairs any device, one device per window. (Skip this if this Mac is already paired with the box.)
        2. 
            
      2. Click Choose the box… (above). Chrome's popup ("localhost:5190 wants to pair") only asks which device this page may talk to: pick nacra.
        3. 
            
      3. macOS then asks to pair with nacra: accept. This is the Bluetooth pairing itself.
        4. 
            
      4. From then on this page remembers the box: Connect connects without prompts, also after a reload.
        5. 
          
      
          
      Each browser origin (http://localhost:5190 here) must choose the box once, even if this Mac is already paired with it. Chrome remembers each box chosen separately (all named nacra); Connect takes the one chosen last, else the one that advertises. For a different box than before, click Choose another box… and pick nacra.
